# Exact pins for the ChuMicro host tooling, applied on top of
# requirements.txt's floors.  CI exports PIP_CONSTRAINT pointing here
# so every run installs the same versions instead of whatever PyPI
# grew overnight; do the same locally when you want a reproducible
# venv:
#
#     PIP_CONSTRAINT=constraints.txt python3 run.py setup
#
# Constraints only pin packages something else asks to install, so
# listing a transitive dependency (chumicro-deploy) is safe: it
# changes nothing unless the resolver reaches for it.  Scope is the
# chumicro family only (the fast-moving parts); the rest of the
# dependency tree rides on requirements.txt's floors.
#
# Tool-owned: `chumicro-workspace update` overwrites this file, which
# is how a template refresh rolls the pins forward.
