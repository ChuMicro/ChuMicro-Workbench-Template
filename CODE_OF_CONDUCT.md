# Code of Conduct

This project follows the same Contributor Covenant code of conduct as
the rest of the ChuMicro ecosystem: read it at
[ChuMicro/CODE_OF_CONDUCT.md](https://github.com/ChuMicro/ChuMicro/blob/main/CODE_OF_CONDUCT.md).

Report unacceptable behavior through GitHub's
[report abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
tools, or by opening a private
[security advisory](https://github.com/ChuMicro/ChuMicro/security/advisories/new)
on the ChuMicro/ChuMicro repository.
